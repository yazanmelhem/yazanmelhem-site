# yazanmelhem.com

موقع شخصي بصفحة واحدة، عربي/إنجليزي، بلا اعتماديات.

## البنية

    content/        المحتوى — هذا ما تحرّره لوحة التحرير
      site.json       الاسم، الصفة، النبذة، بيانات التواصل
      videos.json     الأعمال المرئية
      writing.json    المواد المكتوبة المختارة
      archive.json    الأرشيف الكامل، مقسّمًا إلى مجموعات
    src/template.html القالب — التصميم وبنية الصفحة
    public/           ملفات تُنسخ كما هي (cv.pdf، robots.txt …)
    build.mjs         يدمج المحتوى مع القالب وينتج dist/
    .pages.yml        تعريف حقول لوحة التحرير

## البناء

    npm run build

يُنتج `dist/`. لا يحتاج `npm install` — لا اعتماديات إطلاقًا.

## إعدادات Cloudflare Pages

    Build command:      npm run build
    Build output:       dist
    Root directory:     /

## ملاحظات

- حقل الفيديو يقبل رابط يوتيوب كاملًا أو المعرّف وحده.
- صور أغلفة الفيديو تُجلب من يوتيوب تلقائيًا؛ لا حاجة لرفع صور.
- `metaAr` و`metaEn` يجب أن يتطابق عدد عناصرهما.
- المحتوى يُدمج داخل HTML وقت البناء، لا في المتصفح، حتى تقرأه محركات البحث.
