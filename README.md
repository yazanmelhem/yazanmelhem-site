# yazanmelhem.com

موقع شخصي بصفحة واحدة، عربي/إنجليزي، بلا اعتماديات.

## البنية

كل الملفات في جذر المستودع:

    site.json       الاسم، الصفة، النبذة، صورة الترويسة والصورة الشخصية، زر التواصل، جهات العمل، المشروع قيد الإنتاج
    services.json   الخدمات وما يشهد لكل منها
    others.json     أعمال البودكاست والتلفزيون لجهات أخرى
    field.json      صور «من الميدان»
    videos.json     الأعمال المرئية
    writing.json    المواد المكتوبة المختارة
    archive.json    الأرشيف الكامل، مقسّمًا إلى مجموعات
    template.html   القالب — التصميم وبنية الصفحة
    build.mjs       يدمج المحتوى مع القالب وينتج dist/
    media/          الصور والسيرة الذاتية (ترفعها لوحة التحرير)
    .pages.yml      تعريف حقول لوحة التحرير (Pages CMS)

قسم «قيد الإنتاج» لا يظهر إلا حين يُملأ عنوانه بالعربية في site.json ← project.

## البناء

    npm run build

يُنتج `dist/`. لا يحتاج `npm install` — لا اعتماديات إطلاقًا.

## إعدادات Cloudflare Pages

    Build command:      npm run build
    Build output:       dist
    Root directory:     /

## ملاحظات

- حقل الفيديو يقبل رابط يوتيوب كاملًا أو المعرّف وحده.
- صور أغلفة الفيديو تُجلب من يوتيوب تلقائيًا؛ لا حاجة لرفع صور.
- `metaAr` و`metaEn` يجب أن يتطابق عدد عناصرهما.
- المحتوى يُدمج داخل HTML وقت البناء، لا في المتصفح، حتى تقرأه محركات البحث.
